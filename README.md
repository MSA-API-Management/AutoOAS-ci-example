# AutoOAS CI example project
This repository illustrates the usage of the [AutoOAS GitHub Action](https://github.com/MSA-API-Management/AutoOAS-action). 

The [oas-gen.yml file](.github/workflows/oas-gen.yml) shows an example workflow that uses the AutoOAS GitHub Action. 
In the [Actions](https://github.com/API-Evolution-Management/AutoOAS-ci-example/actions) tab, it is possible to see some example runs of the workflow and the generated artifacts.
