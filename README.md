# AutoOAS CI example project
This repository illustrates the usage of the [AutoOAS GitHub Action](https://github.com/MSA-API-Management/AutoOAS-action). 

The [auto-oas-action.yml file](.github/workflows/auto-oas-action.yml) shows an example workflow that uses the AutoOAS GitHub Action. 
The [Actions](https://github.com/MSA-API-Management/AutoOAS-ci-example/actions) tab shows some example runs of the workflow and the generated artifacts.
